# forge-ai

A modern app clone should not just replicate yesterday's software—it should leapfrog it.
Almost every legacy SaaS has manual tasks that can now be automated with AI.

Output goes in the user's project:

```
forge/ai-spec.md        the AI architecture, model choices, prompts, and cost breakdown
src/lib/ai/             reusable AI provider clients, prompt templates, and streaming handlers
src/app/api/ai/         backend API endpoints for AI flows (server-side only)
```
